% Resumen de estado basado en la auditoría; no es el resumen definitivo.
\abstract{spanish}{
\textit{Resumen provisional.}
Este trabajo construye un modelo de campo escalar masivo a partir de las
derivaciones del equipo y prepara su estudio sobre Schwarzschild. Se desarrollan
el oscilador armónico, la amplitud y la fase, la conservación de energía y
la conexión entre dispersión relativista y Klein--Gordon. En espacio plano
se formula un problema periódico con solución exacta y se justifica un esquema
de diferencias centradas. Se han ejecutado siete evoluciones modales para
comprobar la dispersión y estudiar el error. Los refinamientos conjuntos de
espacio y tiempo presentan órdenes observados próximos a dos. La evolución
en Schwarzschild, el cálculo de frecuencias complejas y la comparación de
estados cuasi-ligados siguen pendientes. El resumen definitivo se completará
cuando se hayan realizado esas etapas.
}
