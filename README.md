# Scalar Field Around a Schwarzschild Black Hole

A university course project by a team of four students, studying the massive
Klein-Gordon field in flat spacetime and around a Schwarzschild black hole.

We aim to numerically verify the flat-spacetime dispersion relation and study
decaying quasi-bound states in Schwarzschild, comparing frequencies obtained
from time evolution and a radial eigenvalue problem. Numerical work will use
Python. No simulations or numerical results are available yet. Kerr calculations
are outside the scope.

## Structure

- `src/`: numerical code.
- `results/`: figures and tables generated by the code.
- `report/`: the report in Spanish, including LaTeX sources, bibliography and images.

Edit [report/main.tex](report/main.tex) and compile from the `report/` directory
to preserve the relative paths to chapters and images.

The `.gitignore` excludes environments, caches, LaTeX auxiliary files, the compiled
report PDF and unused legacy files. These remain local; report sources and required
assets are kept under version control.
